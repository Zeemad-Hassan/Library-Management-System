# Library Management System

A beginner-level C++ console application for managing books in a library.

## Features

- Add Book
- Display All Books
- Search Book
- Update Book Information
- Issue Book
- Return Book
- Delete Book
- Track Book Availability

## Book Information

The program stores:

- Book ID
- Book Name
- Author Name
- Price
- Book Status

## Concepts Used

- C++
- Structures
- Arrays
- Functions
- Loops
- Conditional Statements
- Switch Statement
- Searching
- Updating Records
- Deleting Records
- Array Shifting

## Purpose

This project was created to practice C++ structures, arrays, functions and record management through a simple library management system.
